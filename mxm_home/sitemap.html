Implementation Notes

  • Alle Seiten nutzen das Dark Theme (#2F313C Background)
  • Floating Navigation bleibt über allen Inhalten (z-index: 1000)
  • Ask a Maxo! Chat als Web Component (API integrierbar)
  • Responsive Design: Hamburger-Nav auf <768px
  • Sora Font von Google Fonts (kein offline-Fallback nötig, fast universelle Unterstützung)
  • Deep-Linking zwischen /ki, /flow und Homepage-Sektionen für flexible Navigation
  • Case Studies mit Metadata (Kategorie, Größe, Dauer) für intelligente Filterung
