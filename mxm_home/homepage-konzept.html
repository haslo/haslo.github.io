Durchgängige Patterns (für Claude Code)

Wichtig: Diese Patterns sind keine einzelnen Sections, sondern durchgängige Prinzipien die überall auf der Homepage gelten sollen. Claude Code soll sie bei jeder Section mitdenken.

Kinetic Typography

Prinzip: Text ist nicht statisch — er reagiert auf Scroll und Viewport. Sora ist bold und geometrisch genug dafür. Kinetic Type hebt die Reading Completion um bis zu 37% (Trend-Research).

Wo konkret:
· S01 Hero: Headline baut sich Wort für Wort auf (word-by-word reveal)
· S03 Empathy: Text faded beim Scrollen ein, Highlight-Wörter bekommen Farbe
· S04 Flow: Phase-Titel sliden/faden mit Scroll rein
· S06 Leistungen: Accordion-Headlines könnten beim Hover leicht skalieren oder letter-spacing ändern
· S09 CTA: "Projekt starten." Giant Type, optional subtle scale bei Scroll

Nicht übertreiben: Kein Stretchen, kein Rotieren, kein Cursor-Tracking. Smooth und purposeful, nicht flashy. Fokus auf opacity, transform (translateY/scale), und stagger.

Micro-Interactions

Prinzip: Jede Interaktion gibt sofortiges visuelles Feedback. Die Site fühlt sich lebendig an, nicht busy. Zeigt Handwerk und Detailverliebtheit — walk the talk.

Wo konkret:
· Buttons: Hover → translateY(-4px) + box-shadow. Active → scale(0.98). Neon-Buttons: Glow-Effekt bei Hover
· Cards: Hover → translateY(-8px bis -12px) + shadow-Verstärkung. Staggered entrance beim Scroll-Eintritt
· Accordion: + Icon rotiert smooth zu × (45deg). Content expandiert mit ease-Transition
· Links: Color-transition 0.2s. "Mehr erfahren →" verschiebt sich bei Hover nach rechts (translateX 8px)
· Scroll-Indicator: Bounce-Animation im Hero, verschwindet nach erstem Scroll
· Trust-Zahlen: Counter-Animation beim Scroll-Eintritt (nicht sofort, erst wenn sichtbar)
· Chat-Overlay: Slide-in von unten-rechts mit ease-out
· Nav Pill: Active-Section highlighted, smooth transition zwischen States

Timing: Alle transitions 0.2–0.3s ease. Nie länger als 0.5s. Keine Animation ohne Zweck.

Technische Dokumentation

Frontend Stack

HTML5 semantisch. CSS3 mit CSS Variables, Grid/Flex. JS vanilla für Interaktionen. GSAP 3.12.5 + ScrollTrigger für Animationen.

Animation Library

GSAP 3.12.5 mit ScrollTrigger. Scrub Mode für scroll-linked animations. Snap für Phase-Snapping im Flow-Prinzip.

Typografie

Google Fonts: Sora (300–800). CSS Clamp() für responsive sizing. Line-height 1.3–1.6 je nach Grösse.

Performance Targets

FCP < 1s. TTI < 2s. LCP < 2.5s. CLS < 0.1. Lazy-load Animations via ScrollTrigger.

Responsive Design

Mobile First. Breakpoints: 768px (tablet), 1440px (desktop). Fluid Typography mit clamp().

Accessibility

prefers-reduced-motion: alle Animations disabled. Semantic HTML. ARIA Labels für Accordion states.

Design System: CSS Variables
:root { --ash: #2F313C; /* Dark base */ --elm: #226C6E; /* Teal accent */ --neon: #CCFF00; /* Bright yellow */ --off-white: #F5F3EE; /* Light background */ --ice: #C5DAE0; /* Subtle blue-gray */ /* Responsive Typography */ --giant: clamp(72px, 12vw, 180px); --huge: clamp(48px, 7vw, 110px); --big: clamp(32px, 4.5vw, 72px); --title-xl: clamp(24px, 5vw, 72px); --body-xl: clamp(18px, 3vw, 32px); --body-base: clamp(14px, 2vw, 18px); --eyebrow: clamp(10px, 1.5vw, 14px); }
