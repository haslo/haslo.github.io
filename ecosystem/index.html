🌱 Gwen Widgets

"Health tracking, widget by widget."

An ecosystem of health-tracking iOS apps powered by HealthKit, SwiftUI, WidgetKit, and Swift Charts — sharing a common SPM package for models, services, logic, theming, and chart axis layout.

🏗The Ecosystem

Every app in the Gwen Widgets family shares a common foundation. This means new apps get HealthKit integration, caching, persistent storage, theming, and chart layout for free — and improvements to the shared package benefit every app at once.

Shared Infrastructure

  • HealthWidgetsCore SPM package at Packages/HealthWidgetsCore/ — models, services, logic, theme, chart axis layout
  • App Group group.com.cybergwen.HealthWidgets — shared data across all apps, widget extensions, and watch apps
  • HealthKit for all health data — weight, nutrition, activity, sleep, workouts, water
  • Actor-isolated services with cache layer (CacheStorage) and persistent storage (AppDataStorage)
  • Cute Mode in every app — a single Settings toggle that weaves hearts into the UI. Every heart has a job: backdrops, markers, separators, brand stamps. UX first, cute second.
  • GitHub repo: haslo/health_widgets
