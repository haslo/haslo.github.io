Shared Infrastructure

Reused from OmniWidget

  • Models: DailyHealthEntry, DailyHealthData
  • Services: HealthKitService.fetchWeightSamples(), DailyHealthDataService
  • Views: WeightChartView (adapted), chart components
  • Cache: CacheStorage + HealthKitCacheService
  • Theme: WidgetTheme colors (extended with Scali palette), WidgetStyles
  • Charts: CustomTimeAxisView, LabelLayoutService

New for Scali

  • ScaliEntryService — actor, add/edit/remove weight entries via HealthKit write
  • BidirectionalEmojiService — target-aware status emoji logic
  • TargetProgressService — origin→target progress calculation
  • ColorSchemeConfiguration — rose/red vs ocean/cyan theme switching
  • LogWeightIntent — AppIntent for interactive widget quick-log
  • WatchKit app + complications (4 families)
  • StoreKit 2 one-time purchase

HealthKit

Read + write HKQuantityType(.bodyMass). No other types needed. Weight entries created in-app are written to HealthKit; weights from other sources (Apple Health, other apps) are read.
